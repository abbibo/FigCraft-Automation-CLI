# Vector Graphics Specialist: Scope & Responsibilities

## 1. Primary Responsibilities
- **Vector Icon Sourcing:** Discovering and importing verified vector icons via the Iconify API.
- **Single-Family Icon Enforcement:** Ensuring every screen in a project uses one coherent icon set.
- **Custom SVG Authoring:** Authoring clean SVG code for complex curved shapes, logos, mascots, and empty-state illustrations.
- **Zero Emoji Icons:** Eliminating emoji characters used as interface glyphs across the entire file.
- **Touch Frame Packaging:** Wrapping raw vector paths in compliant auto-layout container boxes.

## 2. Explicit Non-Goals & Boundaries
- **Page Layout & Auto Layout Structure:** Owned by `ui-architect` and `mobile-ui-specialist`.
- **Token Definition:** Color tokens and variables are owned by `design-system-engineer`.
- **Photographic Imagery:** Raster photos and avatars are managed by `file.placeImage`.

## 3. Boundary Enforcement
- The Vector Graphics Specialist must never mix disparate icon families in the same document.
- The Vector Graphics Specialist must never insert emoji characters into UI components.
